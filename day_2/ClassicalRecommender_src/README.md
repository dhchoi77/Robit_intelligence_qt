# 오늘의 클래식 추천기 (Classical Recommender)

클래식을 잘 몰라도 **귀로만** 그날의 취향을 찾아주는 Qt 데스크톱 프로그램.

## 흐름
1. **키워드 선택** — 8개의 느낌(집중/잔잔함/웅장함/활기참/슬픔/몽환/긴장/밝음) 중 하나
2. **3단계 블라인드 선택** — 매 단계 곡 3개를 5초씩만 들려주고, 제목을 숨긴 채 하나를 고름
3. **추천 플레이리스트** — 취향에 가장 가까운 곡들을 제목과 함께 공개, 전체 재생

## 빌드 방법 (Qt Creator)
1. Qt Creator에서 `File > Open File or Project` → 이 폴더의 `CMakeLists.txt` 열기
2. Qt 6 (mingw_64) 키트 선택 후 `Configure Project`
3. 초록 실행(▶) 버튼으로 빌드/실행

> Qt 6 Multimedia 모듈이 필요합니다. Qt 설치 시 "Qt Multimedia"가 체크되어 있어야 합니다.

## ★ 실행 전 꼭 할 일 — 실제 음원 넣기
`tracks.json`의 곡 정보는 이미 들어 있지만, **오디오 파일은 직접 넣어야** 소리가 납니다.
1. Musopen(https://musopen.org) 등에서 퍼블릭 도메인 클래식 녹음을 내려받기
2. 빌드 결과물(실행 파일) 옆에 `music/` 폴더를 만들고 파일을 넣기
3. `tracks.json`의 각 곡 `"file"` 값을 실제 파일명과 맞추기
   - 예: `"file": "music/bach_air.mp3"`
   - Windows에서 MP3 재생이 불안정하면 WAV로 변환해 두면 확실합니다.
4. `"previewStart"`(밀리초)로 미리듣기 시작 지점을 곡마다 조정 가능 (예: `20000` = 20초 지점)

곡을 추가/삭제하려면 `tracks.json`만 편집하면 됩니다. 코드는 고칠 필요 없습니다.

## 코드 구조 (클래스)
- `Features` — 곡의 느낌을 나타내는 5축 특성 벡터. 거리 계산 · 벡터 혼합
- `Track` — 곡 한 개(제목/작곡가/파일/미리듣기 지점/특성)
- `MusicLibrary` — tracks.json 로딩 및 곡 목록 보관 (예외 처리 포함)
- `Keyword` — 8개 키워드와 각 키워드의 출발점 벡터
- `Recommender` — 추천의 두뇌: 프로파일 초기화 → 후보 선정 → 프로파일 갱신 → 최종 추천
- `AudioPreviewPlayer` — QMediaPlayer 래핑, 5초 미리듣기 · 전체 재생
- `KeywordPage` / `ChoicePage` / `PlaylistPage` — 화면 3종
- `MainWindow` — QStackedWidget으로 화면 전환을 조율

## 추천 알고리즘 (요약)
곡마다 5개의 숫자 축(빠르기·분위기·에너지·무게감·시대)으로 '느낌'을 표현한다.
1. 키워드가 취향 공간의 **출발점**을 정한다.
2. 매 단계, 현재 취향에 **가까우면서 서로는 다양한** 곡 3개를 고른다(max-min 다양성).
3. 사용자가 고른 곡 쪽으로 취향 벡터를 끌어당긴다(가중 평균).
4. 마지막에 최종 취향과 가장 가까운 곡들을 정렬해 플레이리스트로 낸다.

곡을 하드코딩으로 연결하지 않으므로, 곡을 추가해도 코드 수정 없이 동작한다.

## 평가 기준 대응
- **클래스 활용**: 역할별로 9개 클래스 분리, UI/로직/데이터 분리
- **알고리즘 구현**: 특성 벡터 + 유클리드 거리 + 다양성 선택 + 온라인 프로파일 갱신
- **가독성 / GUI**: QStackedWidget 흐름, 스타일시트, 한글 주석
- **예외 처리**: 파일 없음/열기 실패/JSON 파싱 오류/곡 부족/오디오 없음/선택 안 함
- **창의성**: 이름을 지운 5초 블라인드 선택, "왜 추천했는지" 설명 기능
