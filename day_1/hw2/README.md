# keyboard — Qt 키보드 시뮬레이터

QWERTY 가상 키보드 시뮬레이터입니다. 마우스 클릭과 실제 하드웨어 키 입력을
모두 지원하며, 한글 입력기(자모 조합)와 Fn 키까지 구현했습니다.

## 구현 기능

### 필수 조건
- **QWERTY 키보드 UI** — 5행 표준 배열
- **입력 텍스트 끝 커서** — `QTextEdit` 커서를 항상 맨 끝에 유지
- **Copy 버튼** — 입력창 텍스트를 시스템 클립보드로 복사
- **Clear 버튼** — 입력창 초기화
- **한/영 전환** — `Kor` 키로 토글 (라벨이 `한`/`Eng`로 바뀜)
- **Caps Lock / Shift / Windows 키** — Caps·Shift는 대소문자 및 기호 전환,
  Win/Ctrl/Alt/Menu는 기능 키로 표시
- **키 클릭 시 눌리는 효과** — 클릭·하드웨어 입력 시 하이라이트

### 추가(가산점) 조건
- **한글 자모 합치기** — 초성/중성/종성 오토마타 기반 조합기(`HangulComposer`).
  복합모음(ㅘ/ㅚ/ㅢ 등), 겹받침(ㄺ/ㅄ 등), 도깨비불 현상(받침의 초성 이동),
  겹받침 단위 백스페이스까지 처리.
- **실제 키보드 입력 감지** — `keyPressEvent`/`keyReleaseEvent`로 물리 키를
  받아 화면 버튼에 눌림 효과를 표시하고 동일한 입력 처리를 수행.
- **Fn(펑션키)** — `Fn` 토글 후 숫자키 1~6으로 음소거/볼륨±/밝기±/재생 등
  동작을 상태줄에 표시(시뮬레이션).

## 빌드

CMake(Qt5/Qt6 자동 감지):

```bash
mkdir -p build && cd build
cmake ..
make
```

또는 qmake를 쓰고 싶다면 아래 `.pro` 내용으로 빌드할 수 있습니다.

## 실행

```bash
cd build
./keyboard
```

## 조작법

- **마우스**: 화면의 키를 클릭
- **물리 키보드**: 창에 포커스를 준 뒤 실제 키를 누르면 동일하게 입력됨
- **한/영**: `Kor` 키 클릭
- **Shift**: 한 번 누르면 다음 한 글자에만 적용(1회성)
- **Caps**: 토글식 대문자 고정
- **Fn**: `Fn`을 눌러 켠 뒤 숫자 1~6
